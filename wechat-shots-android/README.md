# 微信聊天截图导出（WeChat Shots）

一个在手机本机运行的 Android App：通过系统的“无线调试（Wireless ADB）”连接手机自己的 ADB 服务，自动打开微信、搜索指定联系人、逐页滚动聊天记录并截图，最后按联系人/时间归档，可打包 ZIP 分享。

> 只导出**屏幕上看得到的聊天页面截图**，不是导出微信数据库或文字记录；不需要 root，不需要电脑常驻。

- 包名：`com.dsh.wechatshot`
- 版本：1.0.1（versionCode 2）
- 最低系统：Android 11（API 30）
- 目标系统：Android 17（API 37）
- 界面语言：简体中文

## 功能

- 指定微信联系人（备注名也可以），自动搜索并进入聊天。
- 两种导出范围：
  - **全部记录**：从最新消息一直向上翻到聊天顶部。
  - **日期区间**：指定开始/结束日期（含起止日），只保留与区间有交集的页面。
- 自动识别微信聊天中的日期标签：`yyyy年M月d日`、`M月d日`、`yyyy/M/d`、`今天`、`昨天`、`前天`、`星期X`、`HH:mm` 等。
- 可选裁剪状态栏和底部输入框，只保留聊天内容区域。
- 完成后可打包 ZIP，一键调用系统分享。
- 可选同时复制到系统相册（`Pictures/WeChatShots/...`）。
- 前台服务执行，通知栏显示进度，并提供**停止导出**按钮；导出期间下拉通知栏不会把通知栏截进结果。
- 历史记录页：查看、分享、删除以前的导出。
- 本地运行，不上传任何聊天内容。

直接安装已签名的 release APK：

```
dist/wechat-shots-1.0.1-release.apk
```

也可以安装调试包（同一签名，便于覆盖安装）：

## 首次使用：无线调试配对

App 需要先获得手机自身 ADB 的授权。整个过程不需要电脑。

1. 手机连接 Wi-Fi（无线调试依赖 Wi-Fi；不需要和电脑同网）。
2. 打开“设置 → 关于手机”，连续点“版本号”7 次，开启开发者选项。
3. 进入“设置 → 系统 → 开发者选项 → 无线调试”，打开开关。
4. 在无线调试页面点“**使用配对码配对设备**”，保持这个页面打开。页面会显示一个 6 位配对码和一个端口。
5. 回到本 App 的“连接”页：
   - 在“6 位配对码”里填入配对码；
   - 点“发现配对端口”自动发现端口；如果失败，手动填入配对页面显示的端口；
   - 点“配对并连接”。
6. 首次连接时系统会弹出“**允许 USB 调试吗？**”，勾选“始终允许来自这台计算机”，再点“允许”。
7. 顶部状态变成“ADB 已连接”后即可导出。之后一般点“自动连接”即可；如果端口变化或连接失败，重新走一次配对流程。

> 说明：本 App 连接的是手机本机的 adbd（`127.0.0.1` 或 mDNS 发现的地址）。第一次必须点系统授权弹窗；App 会把自己的 ADB 公钥持久化在应用私有目录，后续不需要重复授权。

## 导出聊天记录

1. 打开“导出”页。
2. 填写联系人名称。名称要和微信搜索结果里显示的一致（备注名也可以）。可从“最近使用”快速选择。
3. 选择范围：
   - **全部记录**：从最新消息向上翻到顶部。聊天很长时可能产生几百张截图。
   - **日期区间**：选择开始和结束日期，包含起止日。相邻截图会保留约一半重叠，避免跨页消息被截断。
4. 按需打开：
   - 裁剪状态栏和输入框；
   - 完成后打包 ZIP；
   - 同时保存到相册。
5. 点“开始导出”。导出期间微信会保持在前台，请不要切换应用、锁屏或手动操作微信。
6. 需要提前结束时，下拉通知栏，点通知里的“**停止导出**”。已保存的截图会尽量保留并打包。
7. 完成后可在结果卡里点“分享结果”，或到“记录”页分享/删除。

### 输出位置

应用专属目录（不需要存储权限）：

```
/storage/emulated/0/Android/data/com.dsh.wechatshot/files/Pictures/WeChatShots/
  <联系人>_<yyyyMMdd_HHmmss>/
    001.png
    002.png
    ...
    export.json
    说明.txt
  <联系人>_<yyyyMMdd_HHmmss>.zip
```

- 截图按**从旧到新**编号：`001.png` 是本次导出的最早一页，最后一张是最新一页。
- `export.json` 记录联系人、模式、起止日期、导出时间、图片数量、每页识别到的日期和警告。
- ZIP 包含 PNG、`export.json` 和 `说明.txt`。
- 打开“同时保存到相册”时，会复制到：
  ```
  /storage/emulated/0/Pictures/WeChatShots/<目录名>/
  ```
- 应用专属目录会随卸载 App 一起删除。需要长期保存请分享 ZIP 或打开“同时保存到相册”。

## 实现原理

- 使用 [libadb-android](https://github.com/MuntashirAkon/libadb-android) 在 App 内实现 ADB 客户端，支持无线调试配对、TLS 连接和 mDNS 发现。
- 通过 ADB 执行：
  - `screencap -p` 读取原始 PNG 截图；
  - `input tap/swipe/keyevent` 完成搜索、进入聊天和向上翻页；
  - 对会暴露界面结构的 App（如测试用模拟微信）用 `uiautomator dump` 辅助定位。
- **真实微信 8.x 会向 UiAutomation 和普通无障碍服务隐藏整棵界面树**，因此 App 检测到空树后自动切换为“截图 + 中文 OCR”：
  - 用 ML Kit 中文文字识别（模型内置，不依赖联网）找到搜索框、联系人结果、“前往”“发消息”和聊天日期标签；
  - 根据识别到的文字坐标执行点击/滑动；
  - 每页截图后 OCR 识别聊天区日期，决定保存/跳过/结束。
- 不申请无障碍权限；不需要用户手动开启任何辅助服务。
- 用聊天页顶部联系人标题、底部输入栏和日期标签综合判定聊天界面；标题采用模糊匹配，容忍 OCR 把“输”识别成“輸”等个别错字。
- 每次进入聊天后先滚到最新消息，避免微信恢复上次的滚动位置导致日期区间从中间开始。
- 截图和元数据全部保存在本机；App 不申请联网业务权限用于上传，也不含统计/广告 SDK。

- 日期区间 2026-11-17 ～ 2026-11-17：导出 1 页，`export.json` 记录该页 newestDate=2026-11-17、oldestDate=2026-11-16，ZIP 约 569 KB；截图内容为真实聊天最新页。

### 模拟微信（Android 17 模拟器，1080×2400）

- 历史记录：列表、分享 ZIP、删除目录和 ZIP 均正常。
- 通知栏停止：导出中下拉通知栏会暂停截图；点“停止导出”后服务停止，已保存页面被保留并提示“用户停止了导出，当前截图已尽量保存”。

> 真实微信的界面会随版本/机型变化；如果微信大版本更新后 OCR 找不到入口，请反馈截图或日志。

## 已知限制

1. **只能截取屏幕可见区域**：长聊天会被分成多页，相邻页约 50% 重叠；不是无缝长图。
2. **真实微信走 OCR + 坐标，不是读取控件**：微信隐藏了界面树；App 依赖 OCR 找到搜索框、联系人、“前往/发消息”和日期。微信大版本改版、字体过大、深色模式对比度低或系统缩放变化都可能影响识别。
3. **日期判断是启发式的**：只读取屏幕中间区域的日期标签；OCR 可能把日期识别错。没有日期标签的页面会沿用上一页日期。区间边界页可能包含相邻日期的少量消息。
4. **范围开头无日期页**：如果结束日期不是今天，开头几页还没有滚出日期标签时会被跳过（这些页很可能属于结束日期之后）；会写入警告。
5. **聊天页数上限 400 页**，到上限会提示可能未导完。
6. **不要切换应用/锁屏**：导出期间微信必须在前台；打开通知栏会暂停，打开本 App 或其他应用会中止导出。部分系统在锁屏或省电模式下会限制前台服务。
7. **无线调试可能被系统关闭**：重启、切换 Wi-Fi、关闭开发者选项后需要重新配对/连接。
8. **微信群聊**也可以按群名称搜索进入，但自动化和日期判断与单聊相同；群成员昵称、系统消息等不参与解析。
9. **不导出文字/图片原文件**：结果只有截图，无法复制文字，也不能还原微信数据库。
10. **隐私**：截图可能包含敏感聊天内容。文件只在本机应用目录/相册；分享 ZIP 时请确认接收方。

## 常见问题

**配对码不正确 / 配对失败**
- 配对页面关闭后端口会失效，重新打开“使用配对码配对设备”再试。
- 确认 6 位配对码没有多余空格；端口用配对页面显示的端口。
- 部分系统需要保持屏幕解锁，且不要在配对过程中切走。

**连接成功但提示“执行测试命令失败”**
- 首次连接后 adbd 可能还没完全就绪，App 会自动预热重试；再点一次“自动连接”通常可恢复。
- 确认无线调试仍然打开；必要时到系统无线调试页“取消配对”，重新配对。

**提示“没有搜索到联系人”**
- 联系人名称必须和微信搜索结果一致；可以先用微信手动搜索确认。
- 微信未登录、搜索页被其他窗口遮挡、键盘/输入法异常时也会失败。

**提示“微信已不在前台”**
- 导出过程中不要切到其他 App、不要锁屏、不要打开本 App。需要停止请下拉通知栏点“停止导出”。

**导出很慢**
- 真实微信每页约 2～4 秒（截图 + OCR + 滑动 + 等待），几十页需要几分钟；聊天越长越慢。

**卸载后截图不见了**
- 应用专属目录会随卸载删除；请先分享 ZIP 或打开“同时保存到相册”。

## 构建

环境：

- JDK 17+（本项目使用 Android Studio 自带 JBR 验证）
- Android SDK Platform 37、Build-Tools 36.0.0
- Gradle 9.6.0（wrapper 已包含）

命令：

```bash
# Windows
set JAVA_HOME=E:\androidStudio\jbr
gradlew.bat :app:assembleDebug
gradlew.bat :app:assembleRelease
```

产物：

- `app/build/outputs/apk/debug/app-debug.apk`
- `app/build/outputs/apk/release/app-release.apk`

签名：

- `release-keystore.jks`：release 签名密钥（alias `wechatshot`）
- `keystore.properties`：签名配置
- 请妥善保管这两个文件；丢失后无法用同一签名覆盖升级。

测试模块：

- `mockwechat/`：包名 `com.tencent.mm` 的模拟微信，仅用于自动化测试，不会打进主 APK。
- 安装 `mockwechat/build/outputs/apk/debug/mockwechat-debug.apk` 后，可按本文流程测试导出。

## 目录结构

```
app/src/main/java/com/dsh/wechatshot/
  MainActivity.kt              Compose 界面（连接/导出/记录）
  adb/                         ADB 证书、连接、命令封装
  automation/                  UI 解析、日期标签、OCR、微信自动化
  export/                      导出引擎、前台服务、通知、历史记录
mockwechat/                    模拟微信测试 App
release-keystore.jks           release 签名密钥
keystore.properties            签名配置
dist/                          最终 APK
```

## 隐私说明

- ADB 私钥和证书保存在 App 私有目录 `files/adb/`，不会上传。
- 截图、ZIP、export.json 全部保存在本机。
- App 没有广告、统计、账号系统；网络权限仅用于本机 ADB 连接（TLS/mDNS）。
- 分享行为由你手动触发，分享目标和风险由你自行确认。

## 官网与版本更新

- 官网下载页：<https://qipaclub.top/wechat-shots-app/>（源码 `../website/`）
- 版本信息：<https://qipaclub.top/wechat-shots-app/version.json>
- App 内更新：`app/src/main/java/com/dsh/wechatshot/update/UpdateGate.kt`
  - 启动时 GET `version.json`（5 秒超时，失败静默）；
  - `versionCode` 大于 `BuildConfig.VERSION_CODE` 时弹窗展示更新说明；
  - 下载 APK 到 `cacheDir/update/update.apk`，通过 FileProvider 拉起系统安装器。
- 发布新版本（构建 release APK 后）：

```bash
python ../tools/release_bt.py \
  --apk dist/wechat-shots-1.1.1-release.apk \
  --version 1.1.1 --code 4 \
  --notes "更新说明第一行
第二行"
```

  脚本会通过宝塔 API 分片上传 APK、写入 version.json，并校验公网 HEAD 200 /
  Content-Length 与本地一致、version.json JSON 正确。

- 官网静态文件部署：`python ../tools/deploy_site_bt.py`（详见仓库根 README）。
