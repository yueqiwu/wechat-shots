两种方案 · 按场景选择

想怎么导出，都可以

「笔录工具箱」在电脑上提供两种导出方式：USB 调试连手机自动滚屏截图，或把手机录屏拖进窗口自动转截图。两种方式输出结果一致：不重叠、不重复、顺序完整。

方案 A · 推荐 01

手机截图导出（USB / 无线调试）

手机用数据线连电脑并打开 USB 调试（也可以先 USB 再切无线），工具自动滚动聊天页面、逐屏截图，再按内容拼接去重，一次输出从头到尾不重叠的完整截图。

  • 自动滚屏截图，无需手动截屏
  • 按像素对齐拼接，页与页连续
  • 自动剔除重复段落与坏屏
  • 截图张数不设上限，长聊天也能导到底
连接手机→停在聊天页→自动截图拼接
方案 B · 不用连线 02

录屏转截图

先用手机系统录屏把聊天慢慢滑一遍，再把视频文件直接拖进窗口。工具逐帧分析、对齐拼接，把整段聊天还原成一页页截图并切分页面，不需要连接手机。

  • 拖拽导入视频，无需先转格式
  • 自适应抽帧，自动识别滚动方向
  • 自动裁掉状态栏、标题栏与输入框
  • 可导出 ZIP，一次拿走全部截图
手机录屏→拖入窗口→自动拼接切页

功能亮点

为「完整截图」打磨的细节

从手机采集、对齐去重到分页输出，每个环节都围绕清晰、完整、不重复来做。

自动滚屏

通过 USB 调试或无线 ADB 控制手机聊天界面逐屏滚动、自动截图，长对话也不用守着屏幕；截图张数不设上限。

智能去重

相邻截图的重叠区域按内容比对剔除，只保留新增部分，最终图像里没有重复气泡，页与页上下连续。

本地处理

截图、录屏、拼接全部在这台电脑上完成，不上传服务器，聊天内容只留在你的设备里。

自动更新

启动后自动检查新版本，可在应用内直接下载、校验并替换，完成后自动重新打开；设置页也能手动检查。

长图不中断

连续滚动拼接整段对话，几十屏的长聊天也能合成一条完整长图，顺序不乱，再自动切成单页。

低配也能跑

Python + WebView2 架构，没有 Electron 那种内存开销；安装包内置 adb，解压双击即用，不需要装 Python。

使用说明

解压即用，按引导连接手机

笔录工具箱是绿色软件，下载后解压、双击即可运行，不需要安装 Python 或额外组件；官方包已内置 adb。

  1. 1

    下载并解压

    下载 record-toolbox-1.0.3-win64.zip，解压到任意目录（路径尽量不要带特殊符号），双击目录里的「笔录工具箱.exe」。

  2. 2

    连接手机（仅手机截图方案需要）

    手机用数据线连电脑，按界面里的「还不开启 USB 调试？」引导依次打开开发者选项与 USB 调试，看到「已连接」后即可开始导出；也支持先 USB 再切换为无线调试。

  3. 3

    导出并保存

    在手机上打开要导出的聊天并停在目标位置，点「开始导出」；完成后可按文件夹或 ZIP 保存分页截图。录屏方案则直接把录屏视频拖进窗口即可。

常见问题

你可能想知道的

手机怎么连电脑？USB 调试怎么开？

用数据线把手机连到电脑，在手机上「设置 → 关于手机」连续点击「版本号」7 次开启开发者选项；回到「设置 → 系统 → 开发者选项」，打开「USB 调试」。手机弹出「允许 USB 调试吗？」时点允许。工具界面里也有同样的图文引导，看到「已连接」就可以导出。

也支持无线：先 USB 连一次，再按界面提示切换到无线调试（Android 11+），之后同一 Wi-Fi 下无需插线。

录屏方案怎么用？

先用手机自带录屏，把要导出的聊天从开头慢慢滑到结尾，建议每一屏稍作停留、滚动速度均匀。录屏结束后把视频文件直接拖进工具窗口（或点击选择文件），工具会自动抽帧、按滚动位移拼接，并切分成单页截图。

录屏时请关闭通知横幅与悬浮球，避免遮挡聊天内容影响拼接。

Windows 版需要安装 Python 吗？对电脑要求高吗？

不需要。下载压缩包解压后双击「笔录工具箱.exe」即可运行，官方包已内置 adb 与运行所需组件。系统要求 Windows 10 / 11（自带 WebView2），安装包约 22 MB、解压后约 44 MB。

程序使用 Python + WebView2，没有 Electron 那种内存开销，低配电脑也能流畅运行；录屏方案在很老的机器上可通过降低分析精度换速度。

会自动更新吗？

会。启动后会在后台静默检查官网最新版本（只读取版本清单，不上传数据）；发现新版本时弹窗提示，确认后在应用内下载、校验 SHA-256 并替换程序文件，完成后自动重新打开。设置页也可以手动「检查更新」。

聊天内容会被上传吗？

不会。截图、录屏导入、拼接去重全部在本机完成，工具不会上传聊天图片或内容；只有检查更新时会访问官网读取版本清单。

手机截图导出提示「拼接失败」怎么办？

1.0.2 起已按实测位移自适应调整滑动距离，并在截图后等待页面停稳、自动剔除坏屏，正常情况下不会再整单失败。如果仍遇到，请确认：微信保持在聊天页面、导出期间不要锁屏或手动滑动手机，并更新到最新版本。

Android 版还能下载吗？

可以，本页仍提供 Android 版 APK（Android 11+，支持无线 ADB 与录屏两种方案）。后续会以 Windows 电脑版为主，Android 版可能停止更新，建议优先使用电脑版。
