两种方案 · 按场景选择

想怎么导出，都可以

同一份聊天记录，既可以现场自动翻页拼接，也可以先录屏再离线转图。两种方案输出结果一致：不重叠、不重复、顺序完整。

方案 A · 推荐 01

无线 ADB 截图导出

手机与电脑同一 Wi-Fi，打开无线调试即可连接。App 自动滚动聊天页面、连续截图，再按内容拼接去重，一次输出从头到尾不重叠的完整截图。

  • 自动翻页，无需手动截屏
  • 按像素对齐拼接，边界不重叠
  • 自动识别并去掉重复段落
  • 支持一次导出多个会话
连接无线调试→选择会话→自动拼接导出
方案 B · 无需电脑 02

录屏转截图

先用系统录屏把聊天慢慢滑一遍，再导入录屏。App 逐帧分析、对齐拼接，把整段聊天还原成一页页截图并切分页面，不需要连接电脑。

  • 导入录屏，自动抽帧分析
  • 按滚动位移拼接，画面不重复
  • 自动切分成单页截图
  • 不受设备连接方式限制
系统录屏→导入录屏→自动拼接切页

功能亮点

为「完整截图」打磨的细节

导出的意义是拿一张图就能看完，所以每一个环节都围绕清晰、完整、不重复来做。

自动翻页

通过无线 ADB 控制聊天界面逐屏滚动，一页一页自动截取，长对话也不用守着屏幕。

智能去重

相邻截图的重叠区域按内容比对剔除，只保留新增部分，最终图像里没有重复气泡。

本地处理

截图、录屏、拼接全部在手机本地完成，不上传服务器，聊天内容只留在你的设备里。

批量导出

一次选择多个会话依次导出，文件名自动带上会话名与时间，整理归档更省事。

长图不中断

连续滚动拼接整段对话，几十屏的长聊天也能合成一条完整长图，顺序不乱。

无需 root

基于系统无线调试能力，普通手机即可使用，不刷机、不装框架，卸载即无残留。

常见问题

你可能想知道的

无线调试怎么开？

打开手机「设置 → 关于手机」，连续点击「版本号」7 次开启开发者选项；回到「设置 → 系统 → 开发者选项」，打开「无线调试」。之后可以在无线调试页面看到配对码与端口。

部分品牌路径略有差异：小米在「设置 → 更多设置 → 开发者选项」，OPPO/一加在「设置 → 系统设置 → 开发者选项」，vivo 在「设置 → 系统管理 → 开发者选项」。

自动配对怎么用？

在 App 里进入「无线 ADB 截图导出 → 连接设备」，点橙色「截图自动配对」卡片，再点「自动配对：打开无线调试设置」。首次使用按提示开启一次「自动配对助手」（系统无障碍权限，仅读取无线调试页面的文字，不上传任何内容）。之后 App 会自动打开系统无线调试页、自动点开「输入配对码配对设备」，读取弹窗里的配对码与端口并完成连接。不需要截图，也不需要切回 App —— ColorOS/澎湃等系统会在切走时立刻关闭配对弹窗，自动配对助手正好绕过这个限制。

不想开启无障碍权限时，也可以手动输入配对码与配对端口完成配对；配对成功后，后续同一 Wi-Fi 下会自动连接。如果仍失败，请确认手机和目的地处于同一局域网、无线调试保持开启，并检查是否被系统省电策略冻结后台。

录屏方案怎么用？

先用系统自带录屏，把要导出的聊天从开头慢慢滑到结尾，建议每一屏稍作停留、滚动速度均匀。录屏结束后打开 App，导入这段录屏，App 会自动抽帧、按滚动位移拼接，并切分成单页截图。

录屏时请关闭通知横幅与悬浮球，避免遮挡聊天内容影响拼接。

需要 Android 11+ 吗？

是的。无线 ADB 配对能力需要 Android 11 及以上系统（开发者选项中的「无线调试」），所以 App 的最低系统要求为 Android 11。录屏方案同样运行在 Android 11+。

聊天内容会被上传吗？

不会。截图、录屏导入、拼接去重全部在手机本地完成，应用不会上传聊天图片或内容。App 只在启动时访问官网检查版本更新。

安装时提示「未安装应用」或解析失败怎么办？

通常是下载不完整导致。请通过 Wi-Fi 重新下载，下载完成后核对文件大小是否与页面显示一致；也可能是手机已有更高版本的同包名应用，卸载旧版后再安装。
