# 笔录工具箱（Record Toolbox）

Windows 桌面小工具，用于把微信聊天记录整理成连续的长截图 / 分页截图，并把微信支付、支付宝的
「交易明细证明」整理成可直接提交的 Word 文档。本地处理、不联网上传，面向低配电脑优化
（Python + WebView2，无 Electron）。

## 已有功能

### 1. 手机截图导出（USB 调试 / 无线调试）

1. 手机上开启「USB 调试」（或者先用 USB 连一次再切换为无线）。
2. 在手机上打开微信 → 进入要导出的聊天 → 滑到你希望开始的位置。
3. 点「开始导出」：工具会自动滚动、逐屏截图（相邻截图保留少量重叠，约 **10%～25%**，随机型自动调整），
   然后自动对齐、去重、拼接成长图并切成互不重叠的分页截图。

特点：

- 截图张数不设上限：只要还能继续往下滚，就一路采到聊天顶部为止。
- 截图之间保留少量重叠（约 10%～25%），输出时自动去重，页与页上下连续，不会重复一整块内容。
- 自动裁剪手机状态栏、标题栏和输入框。
- USB 调试引导内置在界面上，按步骤点就行；也支持「先 USB 再切无线」和
  「无线调试配对码」两种无线方式。
- 导出完成后可一键打包 ZIP、打开文件夹。

### 2. 录屏转截图

1. 用手机自带的录屏功能录一段「在微信里匀速向上滚动聊天记录」的视频。
2. 把视频文件**直接拖进**工具窗口的拖放区（或点击选择文件），自动抽帧、分析滚动位移、
   重建完整长图，再切成互不重叠的截图页。

特点：不需要连接手机；支持拖拽导入；自动识别滚动内容区、裁掉状态栏和输入框；可导出 ZIP。

### 3. 交易明细格式化（微信支付 / 支付宝）

1. 在微信里下载「微信支付交易明细证明」PDF、在支付宝里下载「交易明细证明」PDF。
2. 把两个 PDF 分别拖进「交易明细格式化」页（或点选导入），工具会自动解析每一条收入/支出明细。
3. 预览里可以搜索、按平台筛选、勾选删除不需要的条目（「不计收支」行不参与导出）。
4. 点「导出支出」「导出收入」分别生成两个 DOCX；文案按内置模板生成，也可以下载模板改成自己的
   说法后重新上传（模板里保留含 `{{序号}}` 的明细行即可），随时可恢复默认。

特点：完全本地解析、不联网；收入/支出文档分开导出；支持自定义模板；默认模板对齐常见证明材料写法
（「我一共转账 X 笔，共计 X 元。」＋逐条「时间、平台、金额、交易对方、交易单号」）。

### 4. 自动更新

启动后会在后台静默检查官网最新版本（仅访问版本清单，不上传任何数据）。发现新版本时弹窗提示，
确认后在应用内下载、校验 SHA-256 并替换程序文件，完成后自动重新打开；设置页也可手动「检查更新」。

## 实测数据

| 场景 | 输入 | 结果 | 耗时 |
| --- | --- | --- | --- |
| 手机截图导出（模拟器 1080×2400） | 16 张原始截图，实测重叠 13.6% | 长图 26,108 px → 13 页，页高合计=长图高 | 38 s（含自动滚动截图） |
| 手机截图导出（合成样本 720 宽） | 6 张 10% 重叠截图 | 长图 6,580 px → 6 页 | 2 s（拼接） |
| 录屏转截图 | 720×1584 / 24 s 录屏 | 119 页连续截图 + ZIP | 27 s（含分析拼接出图） |
| 录屏转截图（真机录屏） | 432×960 / 2 分 11 秒、快速滑动 | 495 页连续截图，无重复块 | 46 s（含分析拼接出图） |
| 交易明细格式化 | 微信 301 条 + 支付宝 192 条（两份真实 PDF） | 支出 429 条 / 收入 40 条 → 两个 DOCX | < 1 s（解析+导出） |

> 测试机为开发机（20 核）；低配电脑上录屏方案主要耗时在抽帧解码，可调低「分析帧率」或缩短录制时长。

## 运行（源码）

需要 Windows 10/11（自带 WebView2）、Python 3.10+。

```powershell
cd record-toolbox
python -m pip install pywebview
python run.py
```

首次使用「手机截图导出」需要 ADB（Android 平台工具）：

- 把 `platform-tools` 里的 `adb.exe`、`AdbWinApi.dll`、`AdbWinUsbApi.dll`
  放到 `record-toolbox\adb\` 目录（打包版已内置），或在「设置」里指定 adb.exe 路径。
- 没有装 Android SDK 也可以去 Google 官网下载 platform-tools 解压即用。

## 打包

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File tools\build_exe.ps1
```

产物：`dist\笔录工具箱\笔录工具箱.exe`（整个目录可分发，含 WebView2 之外的全部依赖与 adb）。

## 开发

```powershell
# 只起本地服务（便于用 Chrome 调试）
python run.py --headless --print-port
# 前端算法单测（Node 24+；Windows 下必须用 glob 形式）
node --test "tests/*.test.mjs"
# Python 单测
python -m unittest discover -s tests -p "test_*.py"
```

目录结构见 `docs/CONTRACTS.md`（含 HTTP API 与前端模块契约）。

- 「交易明细格式化」加入首页功能入口，界面与既有页面保持 iOS 风格。

### 1.0.3（2026-11）

- 「手机截图导出」不再限制截图张数：只要还能往下滚、没有到聊天顶部，就会一直采集到底
  （之前默认最多 500 屏、上限 2000 屏）。
- 新增自动更新：启动后静默检查官网最新版本，发现新版本可在应用内直接下载、校验并替换，
  完成后自动重新打开；设置页也提供「检查更新」入口。
- 「录屏转截图」支持把视频文件直接拖进选择框，不再必须先点按钮再选文件。
- 以上更新对两种导出方案都生效。

### 1.0.2（2026-11）

- 修复「手机截图导出」在真机上偶发「拼接失败」：`input swipe` 有惯性，实际滑动距离会在
  9.5%～100% 重叠之间剧烈波动，偶尔还会截到惯性/回弹过程中的坏屏。现在改为：
  按实测位移自适应调整滑动距离（目标重叠约 30%）、截图后 0.4s 复测确认页面已停稳、
  几乎没有新内容的重复屏自动跳过；分析前再把「位移反向或匹配失败」的坏屏剔除后重新跟踪，
  不再整单失败。
- 真机实测：连续 3 次 USB 导出均为 10 屏 → 7 页、相邻重叠约 36%，页面内容连续、无重复块。

### 1.0.1（2026-11）

- 修复「手机截图导出」在手机断线/重新插拔后仍使用旧设备名的问题：现在只使用 `adb devices`
  里真实在线的设备序列号，旧的无线调试传输名会被自动过滤；设备离线时自动回退到唯一在线设备，
  都没有时提示重新连接。
- 修复「录屏转截图」对真实手机录屏报「分析没有完成／截图内容存在重复片段」的问题：
  改为按画面内容自适应步进抽帧（不再按固定时间丢帧），自动识别滚动方向、跳过固定不动的
  状态栏/标题栏/输入框，并按内容区精确裁剪，避免拼图里重复出现聊天标题栏。
- 结果页不再显示容易误解的「实测重叠 %」，改为说明页面连续、已去重。

## 隐私

所有截图、视频、拼接计算都在本机完成；工具不联网、不上传任何聊天内容。
