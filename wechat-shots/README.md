# 微信聊天录屏 → 聊天截图（本地网页工具）

把一段微信聊天记录的**录屏视频**，自动切成一张张**首尾相接、不漏不重**的聊天截图，可打包成 ZIP，也能拼成一整张长图。

全程在**浏览器本地**完成：视频不上传、不联网、不需要 ffmpeg、不需要装任何东西，只用浏览器自带的视频解码。

## 在线版

<https://qipaclub.top/wechat-shots/> —— 已部署在 43.142.178.233 的宝塔 nginx 上，纯静态托管。

> 线上版本没有「用样例视频」按钮（24 MB 的样例没上传）；其余功能与本地完全一致。

## 怎么用

1. 双击 `启动.bat`（或在 `wechat-shots` 目录里执行 `python app\serve.py`）。
2. 浏览器会自动打开 <http://127.0.0.1:8765>；没打开就手动访问这个地址。
3. 把录屏 mp4 **拖进**页面（或点"选择文件"）。想先看效果，点"用样例视频"。
4. 点 **开始切图**，等进度条跑完。滑动快、变速、来回滑都可以，不用刻意停。
5. 在缩略图里点掉不想要的（点一下选中/取消），然后：
   - **导出 ZIP**：把所有截图打包下载；
   - **生成整张长图**：把全部内容拼成一张（会按 12000px 自动分段，适合存档）。

## 参数

| 参数 | 说明 | 建议 |
| --- | --- | --- |
| 抽帧密度 | 每秒抽多少帧做分析 | 默认 10 帧；甩得特别猛可调 16/24，慢悠悠地滑 6 也够 |
| 上/下裁剪 | 去掉状态栏、输入栏等不该进截图的部分 | 分析完会自动填好，可手调 |
| 格式 | PNG（无损，文件大）/ JPEG（现场转码，小很多） | 存档用 PNG，发人用 JPEG |

裁剪只影响**导出的截图**，不影响运动分析。上方的小预览窗会实时显示红区（不进截图）在哪里。

## 它是怎么做到"不漏不重"的

不是"挑停留的那一帧"，而是**把整段滚动重建成一张长图，再等分成截图**：

1. **抽帧**：按密度抽帧，每帧缩成 144px 宽的灰度图（只留行签名，原图用完即弃，内存可控）。
2. **找可动区域**：按逐行活动度算出"真正在滚的那一块"（避开状态栏、输入栏这些永远不动的部分）。
3. **逐帧对齐**：相邻两帧用**归一化互相关（NCC）**在整幅高度里搜位移，正反各匹配一次取一致的那组；有亚像素抛物线精修，误差不会随着帧数累积。
4. **补帧**：位移撞到搜索上限、或前后向对不上、或相关度太低 → 判定"这一段太快跟丢了"，只在这些区间里**加倍抽帧**再对齐（最多 3 轮）。所以甩得再快也只是多抽几帧，不会漏内容。
5. **重建主图**：把每帧的绝对滚动位置累加，逐行挑"最清晰的一帧"来填（运动模糊的帧自动让位给清晰的帧）。
6. **切片**：在主图上按目标高度等分，切点会在 ±10% 范围内**挪到最安静的那一行**（消息之间的空白），尽量不把一条消息劈成两半。相邻切片严格首尾相接，所以既不重复也不遗漏。

导出时把主图的每一段重新绘制到画布上（同一批帧按需重新 seek），所以输出的是**原始分辨率**，不是分析用的缩略图。

## 已知限制

- 需要浏览器支持 **H.264/MP4 解码**（Chrome / Edge / Safari 都行）。
- 视频要能被浏览器 seek（常规 mp4 都行；个别手机录的变量帧率视频可能要先转码）。
- 视频特别长时（超过约 4 分钟），抽帧密度会自动降到 1.5~6 帧/秒，避免内存爆掉；只要滑得不至于"一甩跳过一屏多"，仍然能拼起来。
- 甩到**一帧之内跳过一整屏多**（肉眼看到的画面都糊成一片）时，物理上没有可对齐的重叠区，工具会在状态栏提示"有约 X px 内容没抓到"。

## 部署 / 更新线上版

线上是**纯静态**站点，nginx 直接托管，不需要 Python、不需要 Flask。本地的 `serve.py` 只是因为简单静态服务器通常不支持 HTTP Range（视频就 seek 不动）。

```powershell
$env:BT_KEY="<宝塔面板 API 密钥>"
python tools/deploy_bt.py
```

脚本通过宝塔 API 把 `app/` 下的 6 个文件写到 `C:/wwwroot/qipaclub.top/wechat-shots/`，写完会读回校验；会自动去掉线上不用的样例按钮。

## 实测结果

用样例录屏（720×1584，23.8 秒，用户真实变速滑动）实测：

- 抽帧 238 帧（10 帧/秒）→ 其中 4 段太快跟丢，自动补帧 → 重建出 **165,271 px** 的内容总高
- 切成 **129 张**截图（每张约 720×1283，高度 1091~1471 随机浮动以对齐消息间隙），耗时约 **49 秒**
- 相邻截图首尾**严格相接**：把第 k 张末 120 行和第 k+1 张首 120 行比对，相关度 ≈ 0（=没有重复像素）；129 张两两相似度最高 0.55（不同屏，非重复）
- 导出的 ZIP：129 个 PNG，53.8 MB，校验通过
